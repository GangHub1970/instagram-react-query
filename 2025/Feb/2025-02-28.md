### 📖 새로 배운 내용  
  
#### 주제 1: JavaScript 비동기 처리  
📌 JavaScript는 단일 스레드로 동작하지만, 비동기 처리를 통해 효율적인 작업 수행이 가능하다.  
- **비동기 처리**: 코드의 실행 흐름을 차단하지 않고, 다른 작업을 수행할 수 있도록 한다.  
- **이벤트 루프**: 비동기 작업을 관리하고, 콜백 큐에서 대기 중인 작업을 실행한다.  
  
#### 주제 2: Promise와 async/await  
📌 Promise는 비동기 작업의 결과를 나타내는 객체이며, async/await는 Promise를 더 간결하게 사용할 수 있게 해준다.  
- **Promise**: `then()`과 `catch()` 메서드를 사용하여 결과를 처리한다.  
- **async/await**: `async` 키워드로 함수를 정의하고, `await` 키워드로 Promise의 결과를 기다린다.  
  
### 🎯 오늘의 도전 과제와 해결 방법  
- **도전 과제 1**: Promise를 사용한 비동기 함수 작성하기    
  - **해결 방법**: Promise를 반환하는 함수를 작성하고, `then()`을 사용하여 결과를 처리하였다.  
  
- **도전 과제 2**: async/await를 사용하여 비동기 함수 리팩토링하기    
  - **해결 방법**: 기존의 Promise 기반 코드를 async/await로 변경하여 가독성을 높였다.
