### 📖 새로 배운 내용  
  
#### 주제 1: Next.js의 기본 개념  
📌 Next.js는 React 기반의 프레임워크로, 서버 사이드 렌더링(SSR)과 정적 사이트 생성(SSG)을 지원합니다.  
- 페이지 기반 라우팅을 제공하여, 파일 시스템을 통해 자동으로 라우트를 생성합니다.  
- SEO 최적화와 빠른 로딩 속도를 위해 SSR을 활용할 수 있습니다.  
  
#### 주제 2: 페이지 및 라우팅  
📌 Next.js는 파일 시스템을 기반으로 한 라우팅을 제공합니다.  
- `pages` 디렉토리 내에 파일을 생성하면 해당 파일명이 자동으로 URL 경로가 됩니다.  
- 동적 라우팅을 위해 대괄호(`[]`)를 사용하여 URL 매개변수를 정의할 수 있습니다.  
  
#### 주제 3: 데이터 패칭  
📌 Next.js는 다양한 데이터 패칭 방법을 제공합니다.  
- `getStaticProps`: 정적 생성 시 데이터를 패칭합니다.  
- `getServerSideProps`: 요청 시마다 서버에서 데이터를 패칭합니다.
