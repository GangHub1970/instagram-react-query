### 📖 새로 배운 내용  
  
#### 주제 1: FastAPI의 비동기 API 성능  
📌 FastAPI는 비동기 API를 지원하여 높은 성능을 자랑한다.  
- FastAPI는 Starlette를 기반으로 하여 비동기 처리를 최적화함.  
- 비동기 처리를 통해 I/O 작업을 효율적으로 처리하여 응답 속도가 빠름.  
  
#### 주제 2: 비동기 함수(async/await)의 원리  
📌 비동기 함수는 코드의 실행 흐름을 효율적으로 관리한다.  
- `async` 키워드를 사용하여 비동기 함수를 정의하고, `await` 키워드를 통해 비동기 작업의 결과를 기다림.  
- 이를 통해 블로킹 없이 다른 작업을 수행할 수 있어 성능이 향상됨.
